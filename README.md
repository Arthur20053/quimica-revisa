# Química orgânica do zero

Site estático para estudar as duas listas anexadas: cadeias carbônicas, hidrocarbonetos, nomenclatura, álcool, fenol e éter. Inclui 8 aulas, 32 questões inéditas por assunto, um simulado misto com 12 questões inéditas, comparações interativas, revisão rápida e comentários de todas as 30 questões originais.

## Abrir no computador

Abra `index.html` no navegador. O site funciona sem internet. Os PDFs estão na pasta `listas`.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie **o conteúdo desta pasta** para a raiz do repositório (`index.html`, `style.css`, `extras.css`, `content.js`, `app.js`, `favicon.svg` e `listas/`).
2. Em **Settings → Pages → Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `main`, a pasta `/ (root)` e clique em **Save**.
4. Aguarde o link aparecer na mesma tela. O endereço geralmente segue `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

O progresso de aulas, exercícios e o último simulado fica no `localStorage` do navegador usado. Se abrir em outro aparelho ou apagar os dados do navegador, o progresso recomeça.
